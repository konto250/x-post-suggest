OpenAI API

設定を確認中…

APIキーはサーバー側だけで利用します。ローカルでは .env.local、Vercelでは環境変数 OPENAI_API_KEY に設定します。

使い方

  1. 「返信を考える」をブックマークバーに登録。
  2. Xで返信したいポストの詳細を開き、起動。
  3. 内容を確認して返信案を生成・編集。
  4. 「Xで返信する」で返信済みとして保存し、Xで投稿を確定。

画像・動画の内容は解析しません。長文ポストはXで全文を表示してから取り込んでください。相手はユーザー名で区別します。

バックアップ・復元

保存済みの履歴と設定を、JSONファイルとしてこの端末にダウンロードできます。

保存先は通常「ダウンロード」フォルダーです。見つからない場合はブラウザーのダウンロード一覧を確認してください。ファイル名は x-replies-日付.json です。

バックアップから復元する

履歴はこのブラウザー・このURL専用です。ブラウザーデータを消すと失われます。別端末や別URLへ移す場合は、移行元でダウンロードし、移行先でそのファイルを選んでください。復元すると現在の履歴と設定を置き換えます。
